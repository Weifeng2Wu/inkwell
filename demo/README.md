# Glossa 新功能体验

这里放的是本次新增的画板、思维导图，以及 A0、A1 两种尺寸的自由画布海报。每个示例都有完整内容，可以直接打开、修改和导出。

## 打开方式

在 Glossa 中选择「打开项目」，打开这个文件夹：

```text
demo/ in the repository checkout
```

如果已经打开了 Glossa 项目，也可以直接展开文件树中的 `demo`，按下面的顺序打开文件。不需要重新安装依赖、配置模型或连接 Agent。

## 建议体验顺序

| 文件 | 打开后能看到什么 | 可以试试 |
| --- | --- | --- |
| [01-workflow.excalidraw](01-workflow.excalidraw) | 一张包含研究问题、三种工作视图、连接箭头和便签的画板 | 拖动卡片、双击改字、添加箭头、切换源码 |
| [02-research-plan.mindmap.md](02-research-plan.mindmap.md) | 一张向左右展开、带分支配色的思维导图 | 修改字体和颜色、添加左侧分支、空格拖动、导出 SVG |
| [03-auto-layout.poster.json](03-auto-layout.poster.json) | 一张带中文内容和本地图片的 A0 三栏自由画布海报 | 选中元素修改内容和样式、拖动位置、调整大小、导出 |
| [04-freeform.poster.json](04-freeform.poster.json) | 一张已排好的 A1 自由画布海报 | 使用相同的画布控件，比较不同尺寸和版式 |

这些文件展示同一个主题，但分别保存。修改画板不会自动改变导图、海报或配图。

目录和标签页中，导图与海报显示为 `02-research-plan`、`03-auto-layout`、`04-freeform`，并用不同图标区分类型。悬停可查看完整名称；磁盘上的后缀保持不变。

## 1. 画板：把想法摆出来

打开 `01-workflow.excalidraw`，默认进入画布。画面中有一个研究问题、三张工作卡片、一条文件保存说明和一张待办便签。

1. 双击「画板」卡片里的文字，改成自己的研究对象。
2. 拖动卡片，观察连接到卡片的箭头。
3. 在工具栏中选择箭头或文本，补充一条自己的想法。
4. 切换到「源码」，查看对应的 Excalidraw JSON，再返回「画布」。

缩放较小时可以使用画板自己的缩放控件；右上方的「源码」用于查看原始文件。画板菜单中可以保存为图片。

## 2. 思维导图：把想法整理成层次

打开 `02-research-plan.mindmap.md`。双击节点直接改字；选中节点后使用旁边的加减号，右键节点修改样式或添加节点。

| 操作 | 快捷键 |
| --- | --- |
| 添加子节点 | `Tab` |
| 添加同级节点 | `Enter` |
| 编辑选中节点文字 | `F2` |
| 删除选中节点 | `Delete` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z` |
| 平移画布 | 按住 `Space`，同时按住鼠标左键拖动 |
| 缩放画布 | 按住 `Ctrl`（macOS 也可用 `Cmd`）滚动滚轮，以鼠标位置为中心缩放 |

快捷键需要焦点在导图区域；在文字输入框中按 `Enter` 是确认文字。macOS 使用 `Cmd` 代替 `Ctrl`。

可以依次尝试：

1. 选中中心节点，点击左边或右边的「＋」添加对应方向的分支。选中普通节点，外侧「＋」添加子节点，内侧「－」删除该节点及其子节点。
2. 右键「表达」，将这一整条分支移到左侧，再撤销。
3. 右键节点，调整字体、字号、文字颜色、背景色和边框色；也可添加同级或子节点。
4. 按住空格拖动鼠标移动视图，再点击适应视图恢复全图。输入文字时空格仍正常输入。
5. 导出 SVG，检查左右分支及字体颜色。

导图仍保存为 Markdown：一个 `#` 标题和嵌套无序列表，行末的 `inkwell-mindmap` 注释保存样式和分支方向。编辑器直接呈现导图，不再显示源码切换或顶部文字输入栏。

## 3. A0 海报：在自由画布上调整初稿

打开 `03-auto-layout.poster.json`，会直接进入自由画布。这份初稿已排成三栏，点击元素后即可通过属性面板编辑。文件保留原来的名称，实际内容已经统一为 `version: 1`。

建议依次尝试：

1. 点击标题，把「研究想法」替换成自己的课题名。
2. 选中正文，调整字体、字号或颜色。
3. 拖动一张图片，再用坐标和尺寸字段微调。
4. 增加文字后，调整文本框宽高，检查换行和相邻元素是否重叠。
5. 从导出菜单选择 PNG、PDF、SVG 或 PPTX。

海报中的配图位于 `assets/workflow.png`，通过相对路径加载。`assets/workflow.svg` 是这张演示配图的矢量源文件。移动整个 `demo` 文件夹时保留 `assets`，图片仍然可以找到。

Agent 生成和手工创建的海报都以自由画布为主。以前的 `version: 2` 文件也能打开：打开时计算布局，第一次在画布上修改后保存为 `version: 1`。修改文字不会重新排列其他元素；导出前应检查布局。

## 4. A1 海报：尝试另一种版式

打开 `04-freeform.poster.json`。它使用 `version: 1`，文字、色块、图片都有固定的位置，适合对排版做手工调整。

试着选中一个标题或色块并移动，再通过属性面板调整大小。它与上一份 A0 海报使用相同的编辑方式，两个独立文件可以同时打开比较。

## 保存与分栏

示例沿用编辑器现有的自动保存行为。修改一个文件后切换到其他标签，再打开原文件检查内容；也可以关闭并重新打开项目检查保存结果。如果关闭了自动保存，使用 `Ctrl+S` 保存。

通过标签页菜单把画板或导图放到另一侧，可以同时查看海报。示例都是普通本地文件，整份文件夹可以复制到自己的项目中使用。

本文件夹中的文字和配图仅用于功能演示，不包含真实论文、实验结果或性能结论。
